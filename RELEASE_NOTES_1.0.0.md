# AURENYX 1.0.0

Initial public release of **AURENYX — Cognitive Cartography** for Obsidian.

## Included

- complete dark and light theme systems
- AURENYX semantic color architecture
- Noto-based typography hierarchy
- editor and reading view styling
- workspace, tab, sidebar and navigation styling
- properties, tables, code, tags and tasks
- Canvas and Graph styling
- semantic AURENYX callouts
- settings, modals, command palette and status bar
- print and reduced-motion support

## Design intent

Structured complexity. Visible tension. Human decision.

Color is used semantically rather than decoratively; the theme deliberately avoids neon/cyberpunk styling and decorative gold.
